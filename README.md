## 1. Overview

Retailers generate large volumes of customer transaction data, but raw data alone doesn't tell a story. This project analyzes a customer shopping dataset to uncover patterns in spending behavior, discount usage, product performance, and customer loyalty — using a full analytics workflow from raw CSV to (eventually) a business-ready dashboard and report.

The goal is to answer real business questions such as:
- Who spends more — male or female customers?
- Which products perform best, and which get discounted the most?
- Do subscriptions and loyalty correlate with higher spending?
- Which age groups and shipping types drive the most revenue?

## 2. Dataset

- **File:** `customer_shopping_behavior.csv`
- **Rows:** 3,900 customer records
- **Columns:** 18, including:
  - `Customer ID`, `Age`, `Gender`
  - `Item Purchased`, `Category`, `Purchase Amount (USD)`
  - `Location`, `Size`, `Color`, `Season`
  - `Review Rating`, `Subscription Status`, `Shipping Type`
  - `Discount Applied`, `Promo Code Used`, `Previous Purchases`
  - `Payment Method`, `Frequency of Purchases`

## 4. Project Workflow

### Step 1 — Load & Explore Data (Python)
- Loaded the CSV file into a Pandas DataFrame
- Explored structure using `.head()`, `.info()`, and `.describe()`
- Reviewed data types, value counts, and summary statistics

### Step 2 — Data Cleaning (Python)
- Standardized column names (lowercase, underscores instead of spaces)
- Renamed `purchase_amount_(usd)` → `purchase_amount`
- Checked for missing values (found in `review_rating`)

### Step 3 — Load Data into MySQL
- Connected to a local MySQL server using SQLAlchemy + PyMySQL
- Pushed the cleaned DataFrame into a `customer` table inside the `customer_behavior` database using `df.to_sql()`

### Step 4 — SQL Analysis *(in progress)*
Running business-focused SQL queries directly on the MySQL table to answer key questions. See [SQL Analysis](#5-sql-analysis) below for current status.

### Step 5 — Power BI Dashboard *(planned)*

## 8. How to Run

**Python / EDA**
```bash
pip install pandas sqlalchemy pymysql
jupyter notebook project.ipynb
```

**Load data into MySQL**
1. Create a database named `customer_behavior` in MySQL
2. Update the credentials in the notebook (`username`, `password`, `host`, `port`)
3. Run the notebook cells — this will clean the data and push it into a `customer` table

**Run SQL queries**
```bash
mysql -u root -p customer_behavior < sql1.sql
```
Or run the queries directly in MySQL Workbench / any SQL client connected to the `customer_behavior` database.

**Power BI Dashboard** *(once built)*
1. Open the `.pbix` file in Power BI Desktop
2. Update the data source connection to your local MySQL server
3. Refresh the data
